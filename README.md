A make.fun program/v1 entry for [The Best Meal You Ever Had](https://make.fun/c/u-pangg7-the-best-meal-you-ever-had-a3ac0f85) ($2, Growth).

One sentence, at most 200 characters, about the best meal ever had. `main.ts` writes the sentence from `one-line.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validating the gate first: UTF-8 text, 1–200 characters, single line, no leading/trailing whitespace, ends with terminal punctuation.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/best-meal-you-ever-had-test node main.ts
cat /tmp/best-meal-you-ever-had-test/entry.txt
```

## The entry

> Steam rose off my grandmother's soto ayam as the turmeric broth hit my tongue, and for one spoonful every Sunday of my childhood came rushing back to her kitchen table.
